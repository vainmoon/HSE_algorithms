# Отчет по методу Knuth–Morris–Pratt
## Объяснение алгоритма
Для объяснения алгоритма сначала важно разобраться что такое префикс функция. 
Для строки $s$ длины $n$ префикс функция определяется так:
$$
\pi[i] = \max \{ k < i + 1 \mid s[0 \dots k-1] = s[i-k+1 \dots i] \}
$$

То есть $\pi[i]$ — длина наибольшего собственного префикса строки s[0..i], который одновременно является её суффиксом.

Теперь можем перейти к основной идеи алгоритма: возьмем наш паттерн и строку, и соединим символом, который не входит в алфавит паттерна и строки. (В коде используется '#'). Затем вычислим значения префикс функции для соединенной строки. Тогда если $\pi[i] = m, где \; m - длина \; паттерна$, то суффикс строки $s[0...i]$ это подстрока равная искомому паттерну.

## Оценка сложности итогового алгоритма
Для начала, мы вычисляем префикс функцию от соединенной строки. Вычисление префикс функции линейно по сложности. (Получаем $O(n + m)$) Остается пройтись по значениям префикс функции, начиная с m символа. Итого получаем:
$$O(n + m + n) = O(n + m)$$
